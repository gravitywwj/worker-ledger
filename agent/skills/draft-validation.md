# Skill: draft-validation

用于在草稿展示前发现模型遗漏和幻觉。

校验内容：

- 草稿数量与脚本候选金额数量一致。
- 金额按分比较，支持重复金额，不因浮点误差误判。
- 同额候选使用 candidateId 对应原始来源，不能因模型调整顺序而交换账户、渠道或原始说明。
- 每笔都有合法类型、分类和 ISO 时间；明确的账户必须有效，无法判断的实际账户留空并提示待确认。
- 退款/退回的类型与语义一致。
- 转账表示本人账户之间转移，明确的转出和转入账户必须不同；缺少账户时保留草稿，不得直接入账。

校验失败时把具体错误作为工具观察结果返给模型，只允许模型再修正一次；前端仍然只展示可编辑草稿，不直接入账。
