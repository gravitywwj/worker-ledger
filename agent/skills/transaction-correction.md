# 交易纠错技能

## 触发

用户提到记错、改错、更正、修改日期、修改金额、修改分类、修改账户、修改备注，或明确指向上一笔、刚才某笔流水时，进入纠错流程。

## 工作方式

1. 先从账本上下文或 `search_transactions` 只读查找目标流水。
2. 目标必须能由流水 ID 唯一定位；如果有多笔可能匹配，返回 `clarify`，只追问一个最关键的区分信息。
3. 只修改用户明确指出的字段。日期、金额、类型、分类、账户、转入账户和备注都可以是局部修改。
4. 返回 `transaction_update`，包含目标流水 ID、修改字段和简短说明。不要声称已经修改。
5. 软件展示修改前后差异；只有用户点击“确认修改”后才会写入。取消或离开页面都不能改变正式流水。

## 约束

- 不把“刚才”自动理解成任意历史流水；默认只在最近流水中查找。
- 不把修改后的日期数字当成金额，也不把金额数字当成日期。
- 用户没有说改成什么时，必须追问，不得猜测。
- 退款、转账和收入的语义保持原样，除非用户明确要求修改类型。
