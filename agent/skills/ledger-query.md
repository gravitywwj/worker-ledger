# Skill: ledger-query

用于回答本月或上月的收入、支出、结余、分类排行、记录笔数和历史账单查询。

- 只引用传入的账本上下文和查询工具结果。
- 转账不计入收入或支出。
- 退款、报销与工资收入分开表达，不把退款混入工资统计。
- 数据不足时明确说明笔数和统计周期，不生成没有依据的趋势结论。
- 历史查询只引用 `historyQuery` 和 `search_transactions` 的本次查询范围；`countIsPartial` 或 `hasMore` 为 true 时，摘要不是完整明细，完整匹配数量和总额以本地汇总为准。
- 输出简洁中文 JSON：`{"kind":"answer","reply":"..."}`。
